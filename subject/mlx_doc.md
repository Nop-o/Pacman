# Fonctions MLX (wrapper Python)

- **mlx_init** : Initialise la connexion MLX, retourne un pointeur mlx.
- **mlx_release** : Libère les ressources associées au pointeur mlx.
- **mlx_new_window** : Crée une nouvelle fenêtre avec largeur, hauteur et titre.
- **mlx_clear_window** : Efface le contenu d'une fenêtre.
- **mlx_pixel_put** : Affiche un pixel d'une couleur donnée à une position x,y.
- **mlx_destroy_window** : Détruit une fenêtre existante.
- **mlx_new_image** : Crée une nouvelle image aux dimensions données.
- **mlx_get_data_addr** : Récupère l'adresse mémoire des données d'une image.
- **mlx_put_image_to_window** : Affiche une image dans une fenêtre à une position.
- **mlx_destroy_image** : Détruit une image existante.
- **mlx_loop** : Lance la boucle principale d'événements MLX.
- **mlx_loop_exit** : Quitte la boucle principale d'événements.
- **mlx_mouse_hook** : Définit un callback appelé lors d'un événement souris.
- **mlx_key_hook** : Définit un callback appelé lors d'un événement clavier.
- **mlx_expose_hook** : Définit un callback appelé lors d'un rafraîchissement de fenêtre.
- **mlx_loop_hook** : Définit un callback appelé à chaque tour de la boucle principale.
- **mlx_hook** : Définit un callback générique pour un type d'événement X donné.
- **mlx_string_put** : Affiche une chaîne de caractères à une position donnée.
- **mlx_xpm_file_to_image** : Charge une image depuis un fichier XPM.
- **mlx_png_file_to_image** : Charge une image depuis un fichier PNG.
- **mlx_mouse_hide** : Cache le curseur de la souris.
- **mlx_mouse_show** : Affiche le curseur de la souris.
- **mlx_mouse_move** : Déplace le curseur de la souris à une position donnée.
- **mlx_mouse_get_pos** : Récupère la position actuelle du curseur de la souris.
- **mlx_do_key_autorepeatoff** : Désactive la répétition automatique des touches clavier.
- **mlx_do_key_autorepeaton** : Active la répétition automatique des touches clavier.
- **mlx_get_screen_size** : Récupère la largeur et la hauteur de l'écran.
- **mlx_do_sync** : Force une synchronisation immédiate avec le serveur graphique.
- **mlx_sync** : Exécute une commande de synchronisation sur une image ou fenêtre.
